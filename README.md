# ✨ Surprise Amour - Système Solaire & Messages

Une page web romantique et immersive avec :
- 🪐 Système solaire d'amour et cœur 3D animé
- 💬 Trois modes de messages : Messages doux ❤️, Messages babières 😈, Proverbes & Sagesses 😂🇨🇮
- 🎵 Musique d'ambiance avec synchronisation automatique :
  - *Dadju - Reine* pour les messages doux
  - *Télé* pour les messages babières et proverbes
- 👁 Mode Immersion : bouton pour masquer les messages et admirer les animations et les étoiles
- ✨ Interactions tactiles : comètes, mots doux et constellation en forme de cœur

## 🚀 Déploiement sur GitHub Pages (Guide étape par étape)

### Étape 1 : Initialiser et envoyer sur GitHub
Ouvrez un terminal dans ce dossier et lancez :

```bash
git init
git add .
git commit -m "Initial commit - Surprise Amour"
git branch -M main
git remote add origin https://github.com/VOTRE_NOM_UTILISATEUR/NOM_DU_REPO.git
git push -u origin main
```

*(Remplacez `VOTRE_NOM_UTILISATEUR` et `NOM_DU_REPO` par vos identifiants GitHub).*

---

### Étape 2 : Activer GitHub Pages
1. Rendez-vous sur votre dépôt sur GitHub.
2. Cliquez sur l'onglet **Settings** (Paramètres).
3. Dans le menu de gauche, descendez jusqu'à **Pages**.
4. Sous la section **Build and deployment** :
   - **Source** : sélectionnez **Deploy from a branch**
   - **Branch** : choisissez `main` et le dossier `/ (root)`
5. Cliquez sur **Save**.

En quelques instants, votre page sera en ligne à l'adresse :
`https://VOTRE_NOM_UTILISATEUR.github.io/NOM_DU_REPO/`
